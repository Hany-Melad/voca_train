# 📚 English Vocabulary Trainer

An interactive, browser-based application designed to help learners memorize English vocabulary, improve spelling, and test their memory through progressive learning stages.

Built with **HTML, CSS, and Vanilla JavaScript**. No installation or external libraries required.

## ✨ Features

- **Two Training Modes**
  - Practice Mode: Learn words before starting the tests.
  - Test Mode: Start directly with the spelling and memory tests.

- **Three Learning Stages**
  - Stage 0 – Practice: Display the English word and its Arabic meaning.
  - Stage 1 – Spelling Test: Hide the English word and ask the learner to spell it.
  - Stage 2 – Memory Test: Hide the English word completely and test the learner's ability to recall it from memory.

- **Smart Learning System**
  - Two incorrect spelling attempts return the learner to Stage 0.
  - Two attempts are allowed in the memory test.
  - Automatically moves between words.
  - Tracks completed words, remaining words, and incorrect answers.

- **Bookmark System**
  - Bookmark important vocabulary.
  - Remove bookmarks whenever needed.
  - Test bookmarked words again.
  - Copy bookmarked English words separately.
  - Copy bookmarked Arabic meanings separately.

- **Pronunciation**
  - Listen to English word pronunciation using the browser's Speech Synthesis API.

- **Progress & Summary**
  - View training statistics.
  - Review incorrect answers.
  - Retrain words that need more practice.
  - Finish the test at any time using the Home button.

## 🚀 How to Use

1. Open the application in your browser.
2. Enter English words in the first text box.
3. Enter their Arabic meanings in the second text box.
4. Make sure both lists have the same number of lines.
5. Select Practice Mode or Test Mode.
6. Click **Start Training**.
7. Follow the learning stages and track your progress.

## 📖 Learning Philosophy

The application follows a progressive learning approach:

**Practice → Spelling → Memory → Mastery**

The goal is not simply to recognize English words, but to remember and reproduce them independently.
